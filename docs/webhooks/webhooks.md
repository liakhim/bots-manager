Test:

```
npm install
```

Далее потребуется сделать билд приложения
    
```
npm run build
```

---
***Для запуска RabbitMQ:***
```
docker-compose build
```

```
docker-compose up -d
```
Web-интерфейс будет доступен на http://localhost:35672/, сам rabbit запустится на http://localhost:25672/

API будет доступно на http://localhost:8082 (http://localhost:8082/api)

---

*** Примечания: ***
```
- Основной шаблон находится в основном репозитории (DeviceWebSite);
- Дополнительный скрипт в этом репозитории только добавляет данные в rabbit, консумер находится 
в основном репозитории (DeviceWebSite);
- Docker здесь развернут только для проверки добавления, реализовать проверку отправки сообщений здесь не получится;
```
